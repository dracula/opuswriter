### [OpusWriter](https://www.opuswriter.app)

#### Install using Git

If you are a Git user, you can install the theme and keep it up to date by cloning the repo:

```bash
git clone https://github.com/dracula/opus-writer.git
```

#### Install manually

Download using the [GitHub `.zip` download](https://github.com/dracula/opus-writer/archive/main.zip) option and unzip it.

#### Activating theme

1. Open OpusWriter and open the **Appearance Studio**;
2. Import `Dracula.opustheme` (dark) and/or `Alucard.opustheme` (light);
3. Apply the theme from **My Themes** to your series or book;
4. Boom! It's working ✨
